# President-X
**A cyberpunk mystery game where you investigate three clones to uncover who murdered the President and stole their consciousness. Built with Python and Pygame, featuring interactive dialogue, suspect profiling, and multiple endings.**
## How to Run

Before running the game, make sure you have **Python** installed on your computer.

1. Install the required Pygame module (version 2.5 or higher):

```bash
pip install "pygame>=2.5"
```

2. Download or clone this repository.

3. Navigate to the project folder and run the main Python file:

```bash
python main.py
```

Enjoy the game!
